# نَسَق | منصة إدارة المخيمات والاستجابة الإنسانية

منصة ويب عربية متعددة المخيمات لإدارة سجل الأسر، الترشيحات، الكشوفات الرسمية، حسابات مديري المخيمات، والاشتراكات. بُنيت باستخدام Next.js 16 وSupabase PostgreSQL مع عزل بيانات كل مخيم داخل قاعدة البيانات.

## الوظائف الرئيسية

- لوحة مشرف عام لإنشاء المخيمات وتعديلها وتجديد اشتراكاتها وحذفها نهائيًا.
- حساب مستقل لمدير كل مخيم مع صلاحيات محصورة في بيانات مخيمه.
- إدارة الأسر والترشيحات التفصيلية والبحث والتصفية.
- استيراد ملفات XLSX وCSV مع مطابقة الأعمدة والمعاينة وحدود لحجم الملف وعدد الصفوف.
- تصدير كشوفات رسمية وقوالب Excel فارغة للأسر والترشيحات.
- صفحة طباعة باسم المخيم وشعاره وبيانات المسؤول.
- واجهة RTL متجاوبة مع الهاتف وشريط تنقل سفلي للأجهزة الصغيرة.
- Supabase Auth وRLS ومفاتيح خارجية وحذف متسلسل للبيانات التابعة.

## المتطلبات

- Node.js 20.9 أو أحدث.
- مشروع Supabase مهيأ بمخطط المشروع.
- npm 10 أو أحدث.

## التشغيل المحلي

```bash
npm ci
copy .env.example .env.local
npm run dev
```

افتح `http://localhost:3000/login`، أو استخدم منفذًا آخر حسب إعداد التشغيل.

## متغيرات البيئة

```env
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=
SUPABASE_SECRET_KEY=
JWT_SECRET=
NEXT_PUBLIC_APP_URL=
```

المفتاح القابل للنشر فقط يوضع في متغير يبدأ بـ`NEXT_PUBLIC_`. مفتاح Supabase السري و`JWT_SECRET` يظلان على الخادم ولا يرفعان إلى GitHub.

## قاعدة البيانات

- التثبيت الجديد: شغّل `supabase_schema.sql` على مشروع Supabase فارغ.
- ترقية قاعدة قائمة: راجع ونفّذ `database/production_hardening.sql` من خلال migration معتمدة.
- جميع الجداول العامة محمية بسياسات RLS.
- لا تُخزَّن كلمات المرور أو تجزئاتها في `public.users`؛ المصادقة عبر Supabase Auth فقط.

## التحقق قبل النشر

```bash
npm run verify
npm audit --omit=dev
```

`npm run verify` يشغّل اختبارات عقود الإنتاج ثم ينشئ بناء Next.js كاملًا. راجع أيضًا [دليل النشر](DEPLOYMENT.md) و[حالة الجاهزية](LAUNCH_READINESS.md).

## الخصوصية

المنصة تتعامل مع بيانات شخصية وحساسة. يجب على الجهة المشغلة اعتماد سياسة احتفاظ وحذف، وتحديد صلاحيات الموظفين، وتفعيل النسخ الاحتياطي، واختبار الاستعادة، ونشر سياسة خصوصية وشروط استخدام مناسبة للولاية القضائية قبل استقبال بيانات حقيقية.
